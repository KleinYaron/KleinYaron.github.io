Built

Working AI tools built and shipped publicly. Each started with a product problem I wanted to make measurable.

Shipped tool

AI Brand Visibility Monitor

Tests whether AI models mention your brand when answering relevant queries, so visibility becomes something you can measure instead of guess.

  • Build: TypeScript with React Router 7 and Hono, deployed as serverless functions. A queue fans each query out to five models in parallel behind one LLM gateway, and results land in a key-value store with CSV export.
  • Why: it is the measurement problem from my AI-search work last summer, rebuilt as a tool of my own.
github.com/KleinYaron/ai-brand-visibility-template
Shipped tool

AI Feedback Aggregator

Turns scattered customer feedback into prioritized product themes, automating the part of my own job that used to be a spreadsheet.

  • Build: serverless functions over a SQL database, with Llama 3.1 separating actionable feedback from noise and BGE embeddings in a vector index clustering similar themes above an 85% similarity threshold.
  • Scoring: surviving themes are ranked with RICE so the output is a queue, not a report.
github.com/KleinYaron/ai-feedback-aggregator
Shipped tool

Moltbot, a Self-Hosted AI Assistant

I was writing specs for infrastructure I had never operated, so I deployed an AI assistant of my own and now run it end to end, including auth, state and uptime.

  • Build: an edge function handles auth and WebSocket proxying to a Docker container running the gateway, object storage keeps state across restarts, and admin routes sit behind JWT verification.
  • Added: live status indicators, an auto-refreshing admin UI, and a zero-dependency status widget.
github.com/KleinYaron/moltbot-sandbox

About

I am a product manager who builds.

I write code because it is the shortest path to understanding a product. Each tool above started as a question I could not answer from the outside, so I built the thing that answers it. Between them they use TypeScript, React, SQL, APIs, queues, vector embeddings, authentication, storage and serverless infrastructure. Building them helped me understand the systems behind the product decisions I make, and work more effectively with engineering.
